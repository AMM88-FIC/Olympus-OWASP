CODE-1-1
Description
The app shall set the targetSdkVersion to an up-to-date platform version.

Evaluation Procedures
Obtain the Android Manifest and review for adherence with requirements.

 

Verification

Verify that the targetSdkVersion is set to N-2 or above where N is the latest SDK at the time of test.

Verdict scope
This test is binary. The verdict is a yes/no on whether the targetSdkVersion is set to N-2 or above where N is the latest SDK at the time of test. The evidence_table cites the targetSdkVersion record and any supporting context. There is no enumeration to do beyond that.
